# Бот знакомств для українців за кордоном

Telegram-бот (aiogram 3, Firebase Firestore) и веб-админка в одном сервисе Railway.

## Переменные Railway → Variables

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather (обязательно; в коде токена больше нет) |
| `FIREBASE_JSON` | ключ сервисного аккаунта Firebase (JSON целиком) |
| `ADMIN_PASSWORD` | пароль веб-админки |
| `ADMIN_IDS` | необязательно: Telegram ID админов через запятую (можно задать и в админке) |

## Веб-админка

Railway → сервис → Settings → Networking → **Generate Domain**, затем откройте `https://<домен>/admin`.

- **Обзор**: анкеты (мужчины/женщины), новые за сутки/неделю/месяц, активные, взаимные симпатии, лайки, жалобы, приглашения, геолокация, график регистраций, страны, кто больше всех приглашает.
- **Анкеты**: фото и данные, поиск по имени, @нику, ID или тексту, фильтры по стране, полу и статусу (жалобы, скрытые, баны, заблокировали бота, Премиум, младше 18). В карточке: кто лайкнул, симпатии, жалобы; можно забанить, скрыть из ленты, выдать Премиум, удалить анкету, написать человеку от имени бота.
- **Жалобы**: жалобы с кнопки 🚨, сгруппированы по анкете; «Забанить», «Удалить», «Всё в порядке».
- **Рассылка**: по стране, полу и давности последнего захода, с кнопкой-ссылкой; сначала можно отправить себе, видно ход отправки и можно остановить.
- **Настройки**: ID админов, минуты Премиума за друга, порог автоскрытия, список стран, тексты приветствия, отказа от ответственности, политики и «С возвращением».

## Админ в Telegram

- `/myid` — показывает ваш Telegram ID (вставьте его в «Настройки»).
- `/admin` — короткая сводка (только для админов).
- Каждая жалоба приходит админам с фото и кнопками «⛔️ Забанити / 🙈 Сховати / ✅ Все ок».
- Если на анкету пожаловались N разных людей (по умолчанию 3), она скрывается из ленты до решения админа.

## Правила

- Регистрация только с 18 лет. Анкеты младше 18, созданные раньше, видны в админке по фильтру «Младше 18».
- Забаненный пользователь не может пользоваться ботом; скрытую анкету не показывают в ленте.
