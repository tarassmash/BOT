# Бот знакомств для українців за кордоном

Telegram-бот (aiogram 3, Firebase Firestore) и веб-админка в одном сервисе Railway.

## Что умеет бот

- **Лента без лишних сообщений и звуков**: в ленте только фото и две кнопки ❤️ 👎, без текста и анимаций; следующая анкета появляется на месте предыдущей. Имя, возраст, город и описание — в «☰ Ще» → «ℹ️ Про …», там же суперлайк и жалоба. Суперлайк и жалоба на текущую анкету — в меню «☰ Ще».
- **Фирменные фишки**: 🏠 «Земляки» (откуда родом в Украине, земляки выше и с отметкой 🤝), ☕️ «Вільний сьогодні» (на 24 часа анкета выше с меткой «можно на кофе»), 💌 суперлайк раз в сутки с коротким сообщением.
- **Моя анкета**: менять фото, текст, имя, возраст, страну, локацию и город без удаления анкеты; пауза или удаление.
- **Фильтры** кнопками: страна и возраст (готовые диапазоны или свой).
- **Мои лайки**: сколько человек лайкнули; с Премиумом — список с кнопками «Взаємно / 👎».
- **Приглашение друга**: Премиум получают оба, кнопка «Надіслати другу».
- **Скарги с причиной** (фейк, неповнолетний, спам, 18+), взаимная симпатия с кнопкой «Написати».
- Меню команд: /search, /likes, /profile, /help, /start. В группах бот молчит.

### В стиле Дайвинчика

- Анкета: до 3 фото или видео, город («Оля, 24, Аліканте – текст»); в ленте без текста — только фото и ❤️ 👎; если фото несколько — кнопка «📷 1/3 ▸» листает их на месте.
- После регистрации — «Так виглядає твоя анкета. Все вірно?»; в «Моя анкета» есть «🔄 Заповнити заново» (лайки и симпатии сохраняются) и «🏙 Місто».
- «Ти сподобався(-лась) N людям! Показати?» и напоминания тем, кто не заходил: если ждут лайки — раз в 2 дня, иначе раз в неделю (только днём).
- Взаимность: «Є взаємна симпатія! Сподіваюсь, добре проведете час 😉 Починай спілкуватися 👉 @username».

## Приложение внутри Telegram (Mini App)

Кнопка «❤️ Знайомства» слева от поля ввода в чате с ботом (и «📱 Відкрити застосунок» в меню) открывает приложение:

- **Анкети** — фото на весь экран, свайп вправо/влево или кнопки ❤️ 👎; тап по левой/правой половине листает фото; ⓘ — описание, 💌 суперлайк и 🚨 жалоба.
- **Лайки** — сколько человек лайкнули; с Премиумом — сетка фото с ответом «❤️ Взаємно / 👎».
- **Симпатії** — все взаимные симпатии с кнопкой «Написати».
- **Регистрация прямо в приложении** — 7 коротких шагов: имя, возраст (18+), кто/кого ищет, страна и город, до 3 фото/видео (загружаются из галереи, сжимаются автоматически), о себе и «звідки родом», локация и согласие с правилами. Бонус за приглашение засчитывается и здесь.
- **Профіль** — фото (добавить, удалить, сделать главным), имя, возраст, пол, кого ищет, страна, город, «звідки родом», текст, локация, ☕️ «вільний сьогодні», ⏸ пауза, фильтры, приглашение друзей, правила, удаление анкеты.
- Уведомления бота («тебя лайкнули», напоминания, «друг зарегистрировался») открывают приложение. Новичкам по /start бот предлагает создать анкету в приложении или в чате.

### Только приложение (по умолчанию)

В чате с ботом нет меню и регистрации: на /start — одна кнопка «❤️ Відкрити FlirtUA», на любое другое сообщение или старую кнопку — «Усе — у застосунку 👇» с кнопкой (старые «Мої лайки» / «Моя анкета» открывают нужную вкладку).
В чате остаются: уведомления о лайках, симпатиях и ответах поддержки (с кнопкой в приложение), оплата, /support, /terms и команды админов.
Меню команд бота: только «Відкрити знайомства», «Підтримка», «Умови». Выключается в админке → «Настройки» → «Только приложение».

### Открывать сразу приложение (по умолчанию)

1. @BotFather → /mybots → бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставьте адрес `https://<домен Railway>/app`.
2. Railway → Variables → `MAIN_APP=1`.

После этого ссылка **`https://t.me/<бот>?startapp`** открывает приложение сразу, без чата; приглашения друзей тоже ведут прямо в приложение (`?startapp=ref_…`, бонус засчитывается). В профиле бота появляется кнопка «Відкрити». В чате приложение открывается кнопкой «❤️ Знайомства» слева от поля ввода и кнопками в сообщениях бота (по /start — «❤️ Відкрити знайомства»). Кнопки под полем ввода нет: из такой кнопки Telegram открывает приложение без данных пользователя. Если человек открыл приложение по ссылке, не нажав «Почати», приложение само попросит разрешение писать ему (нужно для фото и уведомлений о симпатиях).

Включение: Railway → Settings → Networking → **Generate Domain** (тот же домен, что и для админки). Бот сам найдёт адрес (`RAILWAY_PUBLIC_DOMAIN`) и поставит кнопку; можно задать адрес вручную в `WEBAPP_URL` (например `https://мой-домен/app`). Вход в приложение — по подписи Telegram, без паролей.

## Премиум за звёзды Telegram

Оплата прямо внутри Telegram — зірками (Telegram Stars), без карт, провайдеров и сторонних сайтов.

- **В приложении**: вкладка «Лайки» (если есть непросмотренные лайки) и «Профіль» → «💎 Преміум» — карточки тарифов; нажатие открывает родное окно оплаты Telegram поверх приложения, после оплаты Премиум включается сам.
- **В чате**: /premium, «☰ Ще» → «💎 Преміум», кнопка в «Мої лайки» и в «Запросити друга» — бот присылает счёт.
- Тарифы по умолчанию: 7 дней — 75⭐, 30 дней — 250⭐, 90 дней — 600⭐. Меняются в админке → «Настройки» (там же можно выключить продажу).
- Дни добавляются к текущему сроку. Оплаченный Премиум сохраняется, даже если человек удалит анкету и создаст новую.
- Каждый платёж засчитывается ровно один раз; счёт проверяется перед списанием (цена, тариф, плательщик).
- /terms — условия оплаты, /paysupport — обращение по оплате (приходит админам).
- **Админка → «Оплаты»**: баланс звёзд бота, выручка за сегодня/7/30 дней, график, разбивка по тарифам, список платежей и кнопка «Вернуть» (звёзды возвращаются, оплаченные дни снимаются). В карточке анкеты видно историю оплат.
- Звёзды выводятся через @BotFather → бот → Balance.

## 🎨 Дизайн приложения (админка → «Дизайн»)

- **Живой предпросмотр** приложения справа: онбординг, регистрация, лента, «Це взаємно!», пустая лента, лайки, симпатии, профиль — изменения видны сразу.
- **Цвета** (9 цветов темы) и **шрифты** (только с украинской кириллицей).
- **Тексты онбординга**: заголовки, подзаголовки, пункты сравнения и фишек.
- **Картинки экранов** через fal.ai: главная картинка онбординга, картинки экранов 2–4, фон «Це взаємно!», пустая лента. Описание → «Сгенерировать» (1–3 варианта) → «Поставить». Картинка сохраняется у нас, ссылки fal не нужны.
- **«✨ Придумать дизайн целиком»**: стиль словами → нейросеть подбирает цвета, шрифты, тексты и описания картинок; «Сгенерировать все картинки» — все 6 разом (~$0.30).
- «Сохранить дизайн» — и приложение у всех открывается в новом дизайне. «Вернуть стандартный дизайн» — назад к «Наші поруч».

Нужна переменная **`FAL_KEY`** в сервисе бота (для картинок и «Придумать»). Цвета, шрифты и тексты работают и без неё.

## Поддержка

- **В приложении**: «Профіль» → «💬 Підтримка» — чат с поддержкой (ответы видны там же, непрочитанные — значком). Из «Умови оплати» — кнопка «Написати в підтримку».
- **В боте**: /support (любой вопрос), /paysupport (оплата), «☰ Ще» → «💬 Підтримка».
- **Админам в Telegram** приходит каждое обращение с кнопкой «✍️ Відповісти».
- **Админка → «Поддержка»**: список обращений (непрочитанные сверху, счётчик на вкладке), переписка, «Ответить», «Ответить и закрыть», ссылка на анкету. Ответ приходит человеку от бота и появляется в приложении.

## Переменные Railway → Variables

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather. Старый токен в коде публичный — отзовите его (/revoke) и задайте новый здесь |
| `FIREBASE_JSON` | ключ сервисного аккаунта Firebase (JSON целиком) |
| `ADMIN_PASSWORD` | пароль веб-админки |
| `FAL_KEY` | ключ fal.ai — генерация картинок и дизайна в админке → «Дизайн» |
| `ADMIN_IDS` | необязательно: Telegram ID админов через запятую (можно задать и в админке) |

## Веб-админка

Railway → сервис → Settings → Networking → **Generate Domain**, затем откройте `https://<домен>/admin`.

- **Обзор**: анкеты (мужчины/женщины), новые за сутки/неделю/месяц, активные, взаимные симпатии, лайки, жалобы, приглашения, геолокация, график регистраций, страны, кто больше всех приглашает.
- **Анкеты**: фото и данные, поиск по имени, @нику, ID или тексту, фильтры по стране, полу и статусу (жалобы, скрытые, баны, заблокировали бота, Премиум, младше 18). В карточке: кто лайкнул, симпатии, жалобы; можно забанить, скрыть из ленты, выдать Премиум, удалить анкету, написать человеку от имени бота.
- **Жалобы**: жалобы с кнопки 🚨, сгруппированы по анкете; «Забанить», «Удалить», «Всё в порядке».
- **Рассылка**: по стране, полу и давности последнего захода, с кнопкой-ссылкой; сначала можно отправить себе, видно ход отправки и можно остановить.
- **Настройки**: ID админов, минуты Премиума за друга, порог автоскрытия, список стран, тексты приветствия, отказа от ответственности, политики и «С возвращением».

## Админ в Telegram

- `/myid` — показывает ваш Telegram ID (вставьте его в «Настройки»).
- `/admin` — короткая сводка (только для админов).
- Каждая жалоба приходит админам с фото и кнопками «⛔️ Забанити / 🙈 Сховати / ✅ Все ок».
- Если на анкету пожаловались N разных людей (по умолчанию 3), она скрывается из ленты до решения админа.

## Правила

- Регистрация только с 18 лет. Анкеты младше 18, созданные раньше, видны в админке по фильтру «Младше 18».
- Забаненный пользователь не может пользоваться ботом; скрытую анкету не показывают в ленте.
